Irani Café

EST. 1953 · CAMP, PUNE

The counter, the stock book and the staff register, on one screen.

Chai goes out in ninety seconds. The bill, the stock count and the shift record should keep up. This system replaces the four paper registers the café runs on today.

Seven modules

Each module maps to one screen in the system.

Counter

Take the order, add items, settle the bill by cash, UPI or card.

Bills

Every bill of the day, reopenable and printable.

Stock

Milk, tea, bun, kheema. Falls as orders are billed.

Staff register

Records, shifts, attendance and monthly salary.

Reports

Day and week sales, top items, payment split.

Regulars

Regular customers — name, contact and visit history.

Database

Relational SQL ledger: inspect tables, column types and foreign keys.

Technologies used

Python 3 HTTP API (standard library), SQLite3 relational database, HTML5, CSS3, JavaScript (ES6). Data persists across sessions and browser refreshes in cafe.db.
